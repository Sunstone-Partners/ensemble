# Project Constitution: Pilot Fixture

> Minimal constitution for the skills eval fixtures. It carries the article headings and checks the Constitution Gate reads.

## Article I: Requirements are testable

Every requirement has at least one acceptance criterion written as Given/When/Then.

## Article II: Planning documents contain no implementation

A PRD or TRD describes what and why. It never contains source code or build output.

## Article III: Scope is explicit

Every document states its non-goals. An unresolved question is marked [NEEDS CLARIFICATION] rather than guessed.
