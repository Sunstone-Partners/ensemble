# @sunstone-partners/ensemble-ai

AI SDK conventions skills for Claude Code.

## Installation

```bash
claude plugin install @sunstone-partners/ensemble-ai
```

## Contents

- `skills/using-anthropic-platform`
- `skills/using-openai-platform`
- `skills/using-perplexity-platform`
- `skills/using-weaviate`
- `skills/building-langgraph-agents`

Skills are short conventions-and-gotchas notes (the model already knows the framework basics); they are loaded automatically by Claude Code from `skills/`.
